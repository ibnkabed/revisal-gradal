# Code of Conduct

We want this project to be a respectful place for everyone who takes part: teachers, students and developers.

- Treat others with respect and kindness, and criticize ideas, not people.
- No abuse, harassment or discrimination of any kind.
- Do not post anyone's personal data, keys or passwords.

The repository's maintainer may remove any comment or contribution that breaks this code, and block anyone who repeats it.
